# ResNet-Computer-Vision
# Image Classification & Custom 2D Convolution

## Overview
This project focuses on deep learning and computer vision utilizing **PyTorch**. The primary objective is to perform image classification using the **ResNet** architecture, alongside a from-scratch mathematical implementation of a 2D convolution algorithm. This dual approach demonstrates both the ability to utilize advanced industry-standard frameworks and a strong foundational understanding of neural network mechanics.

## Key Features
* **ResNet Architecture:** Implemented a Convolutional Neural Network (CNN) based on ResNet (specifically ResNet18) for image classification.
* **Dataset Processing:** Integrated and preprocessed the **CIFAR-10** dataset, including image resizing, tensor conversion, and normalization.
* **Custom 2D Convolution:** Built the core 2D convolution operation entirely from scratch without relying on high-level PyTorch wrapper functions (like `nn.Conv2d`), showcasing low-level algorithmic design.
* **Model Training & Evaluation:** Handled data augmentation, visualization of dataset classes, training loops, and evaluation metrics.

## Technologies Used
* **Python**
* **PyTorch & TorchVision** 
* **NumPy**
* **Matplotlib** (for image visualization and performance graphs)
* **Jupyter / Google Colab**

## Project Structure
The code is thoroughly documented within the provided Jupyter Notebook, covering:
1. Data loading, augmentation, and normalization using CIFAR-10.
2. Visualizing sample images across different classes (Plane, Car, Bird, Cat, etc.).
3. The custom 2D convolution implementation.
4. Model architecture setup (ResNet18 pre-trained weights evaluation).
5. Training process, loss calculation, and accuracy evaluation.
